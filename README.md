One honest status page line for a total server outage: every service is down, the agent cannot reach any server to check what failed, and it does not know when they will return.

`main.py` reads `entry.txt`, checks the gate (UTF-8, 1–160 characters, one line, no control characters), and writes it to `/output/entry.txt` with mode 0644.
